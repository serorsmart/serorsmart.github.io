About Me

I am a passionate mobile web development student building my skills in creating modern, responsive, and user-friendly websites. My journey into web development has introduced me to HTML5, CSS3, JavaScript, and the creative process of turning ideas into functional websites.

Through hands-on coursework and personal projects, I have gained experience designing web page layouts, working with CSS Grid and Flexbox, adding interactive features with JavaScript, and using Git and GitHub to manage my projects.

Every project gives me an opportunity to learn something new, solve problems, and improve my understanding of web development. My goal is to continue growing as a developer, strengthen my technical and creative abilities, and build websites that provide meaningful experiences for users.

My Projects

Northstar Observatory

Northstar Observatory is a space-themed website that I developed as part of my web development coursework using HTML, CSS and JavaScript

Movie Party

Movie Party is a movie-discovery website developed using HTML, CSS, and JavaScript. It features a cinematic interface, responsive navigation, and an interactive movie-search function. The project integrates the TMDB (The Movie Database) API to retrieve movie information dynamically, demonstrating my skills in API integration, JavaScript, and working with external data.

Fork & Flame

Fork & Flame is a modern, mobile-responsive restaurant and food-delivery website developed using HTML, CSS, and JavaScript. The project features an inviting, family-friendly design, engaging food imagery, stylish navigation, and carefully organized content sections. It focuses on creating an attractive, user-friendly browsing experience across desktop, tablet, and mobile devices while demonstrating my skills in responsive web design, page layout, and front-end development.
